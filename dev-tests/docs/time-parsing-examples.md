# 时间解析功能说明

## 🕐 AI时间解析规则

### 输入格式
- 用户文本描述：包含食物和时间信息
- 当前时间：浏览器当前时间，格式为 HH:MM (24小时制)

### 解析规则

#### 1. 明确时间表达
| 用户输入 | 解析结果 | 说明 |
|---------|---------|------|
| "早上8点吃了面包" | "08:00" | 直接转换为24小时制 |
| "上午10点半喝咖啡" | "10:30" | 上午时间 + 半点 |
| "下午3点吃苹果" | "15:00" | 下午时间 + 12小时 |
| "晚上7点半吃晚饭" | "19:30" | 晚上时间 + 12小时 + 半点 |
| "中午12点吃午饭" | "12:00" | 中午时间 |
| "凌晨2点吃夜宵" | "02:00" | 凌晨时间 |

#### 2. 相对时间表达
| 用户输入 | 当前时间 | 解析结果 | 说明 |
|---------|---------|---------|------|
| "刚刚吃了香蕉" | "14:30" | "14:30" | 使用当前时间 |
| "刚才喝了水" | "09:15" | "09:15" | 使用当前时间 |
| "刚吃完午饭" | "13:45" | "13:45" | 使用当前时间 |

#### 3. 无时间信息
| 用户输入 | 当前时间 | 解析结果 | 说明 |
|---------|---------|---------|------|
| "吃了一个苹果" | "16:20" | "16:20" | 默认使用当前时间 |
| "喝了一杯牛奶" | "07:30" | "07:30" | 默认使用当前时间 |

#### 4. 复杂时间表达
| 用户输入 | 解析结果 | 说明 |
|---------|---------|------|
| "今天早上8点半吃的早餐" | "08:30" | 忽略"今天"，提取具体时间 |
| "昨天晚上9点吃了夜宵" | "21:00" | 注意：这里可能需要特殊处理 |
| "15:30喝了下午茶" | "15:30" | 直接使用24小时制时间 |

## 📱 前端集成

### 数据传递
```javascript
// 获取当前时间
const now = new Date();
const currentTime = `${now.getHours().toString().padStart(2, '0')}:${now.getMinutes().toString().padStart(2, '0')}`;

// 传递给API
formData.append("currentTime", currentTime);
```

### 显示效果
```
150g · snack · afternoon · 14:30
```
