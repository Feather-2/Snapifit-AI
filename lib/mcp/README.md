# 前端为主的安全MCP架构

## 设计理念

基于安全考虑，采用**前端为主、后端代理**的MCP集成方案，既保证了功能完整性，又最大化了安全性。

## 安全特性

### 1. 多层安全防护

- **前端过滤**: 敏感数据在发送前即被过滤
- **白名单机制**: 只允许预定义的安全工具
- **参数验证**: 严格验证所有输入参数  
- **结果过滤**: 移除响应中的敏感信息
- **执行限制**: 超时、并发、大小限制

### 2. 风险隔离

- **进程隔离**: MCP工具在受限环境中执行
- **网络隔离**: 只允许连接到预配置的安全服务器
- **数据隔离**: 用户数据不会泄露给外部服务
- **会话隔离**: 每个用户的工具调用相互独立

## 实现优势

### ✅ 安全性

- **最小化攻击面**: 服务器端只做代理，不执行复杂逻辑
- **输入输出过滤**: 双重过滤确保数据安全
- **资源限制**: 防止恶意工具消耗资源
- **会话隔离**: 用户数据不会交叉污染

### ✅ 用户体验

- **智能建议**: 根据聊天内容自动推荐工具
- **一键执行**: 预填参数，降低使用门槛
- **结果集成**: 工具结果无缝融入对话
- **实时响应**: 前端逻辑保证快速响应

### ✅ 可扩展性

- **标准接口**: 基于MCP协议，易于接入新工具
- **模块化设计**: 前后端分离，便于独立扩展
- **配置驱动**: 通过配置控制工具可用性
- **插件机制**: 支持动态加载新工具类型

## 使用示例

### 1. Chat页面集成

```tsx
// 在Chat组件中集成MCP
const {
  suggestions,
  executeTool,
  toolResults,
  handleMessageChange
} = useMCPIntegration({
  expertRole: selectedExpert,
  healthData: todayLog,
  userProfile: userProfile
})

// 监听输入变化
useEffect(() => {
  handleMessageChange(input)
}, [input, handleMessageChange])

// 渲染工具建议
<MCPToolIntegration
  suggestions={suggestions}
  onToolExecute={executeTool}
  embedded={true}
/>
```

## 安全配置

```typescript
// 工具白名单
const ALLOWED_TOOLS = [
  'nutrition_calculator',   // 营养计算
  'bmi_calculator',        // BMI计算  
  'exercise_database_search', // 运动查询
  'meal_planner',          // 膳食规划
  'chart_generator'        // 图表生成
]

// 执行限制
const EXECUTION_LIMITS = {
  timeout: 30000,          // 30秒超时
  maxConcurrentCalls: 3,   // 最多3个并发
  maxResponseSize: 102400, // 100KB响应限制
}
```
