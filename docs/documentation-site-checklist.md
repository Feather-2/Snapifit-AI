## 🎯 快速启动命令

```bash
# 1. 创建项目
git clone https://github.com/your-username/snapfit-docs.git
cd snapfit-docs

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev

# 4. 构建生产版本
npm run build

# 5. 预览生产版本
npm run preview

# 6. 部署到Vercel
vercel --prod
```
