# 营养数据编辑功能测试

## 🍎 功能概述

新增的营养数据编辑功能允许用户在食物卡片的编辑模式中：

1. **编辑基本信息**：食物名称、份量、餐次、时间段、具体时间
2. **编辑营养数据**：每100g的宏量营养素含量
3. **自动重新计算**：修改任何数据后自动重新计算总营养成分

## 🎯 编辑界面布局

### 基本信息编辑区域

## 🔄 自动计算逻辑

### 1. 修改份量时
```javascript
// 用户修改份量从 80g → 120g
const ratio = 120 / 100; // 1.2
const newCalories = 265 * 1.2 = 318; // 自动重新计算
```

### 2. 修改营养数据时
```javascript
// 用户修改每100g卡路里从 265 → 300
const ratio = 80 / 100; // 0.8 (份量80g)
const newTotalCalories = 300 * 0.8 = 240; // 自动重新计算总卡路里
```

## 📱 用户交互流程

### 编辑基本信息
1. 点击食物卡片的编辑按钮
2. 修改食物名称、份量、餐次等
3. 修改具体时间（支持时间选择器）
4. 点击保存

### 编辑营养数据
1. 在编辑模式中点击"编辑营养"按钮
2. 展开营养数据编辑区域
3. 修改各项营养成分数值
4. 实时看到总营养成分的变化
5. 点击"隐藏营养"收起编辑区域
6. 点击保存确认所有修改

## 🎨 UI/UX 设计要点

### 1. 渐进式披露
- 营养编辑区域默认隐藏
- 点击"编辑营养"按钮展开
- 避免界面过于复杂

### 2. 实时反馈
- 修改任何数值后立即重新计算
- 无需等待保存就能看到变化
- 提供视觉反馈确认修改

### 3. 响应式设计
- 在小屏幕上营养数据使用2列布局
- 在大屏幕上使用4列布局
- 保持良好的触摸体验

### 4. 数据验证
- 数值输入支持小数点
- 防止输入负数
- 自动格式化显示

## 🔧 技术实现细节

```typescript
const [isEditingNutrition, setIsEditingNutrition] = useState(false);
const [editedEntry, setEditedEntry] = useState<FoodEntry>({ ...entry });
```

### 营养数据更新
```typescript
const handleNutritionChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const { name, value } = e.target;
  const numValue = Number.parseFloat(value) || 0;

  // 更新每100g营养成分
  const updatedNutrition = {
    ...editedEntry.nutritional_info_per_100g,
    [name]: numValue
  };

  // 重新计算总营养成分
  const ratio = editedEntry.consumed_grams / 100;
  const updatedTotal = Object.entries(updatedNutrition).reduce(
    (acc, [key, value]) => {
      if (typeof value === "number") {
        acc[key] = value * ratio;
      }
      return acc;
    },
    {} as any,
  );

  setEditedEntry({
    ...editedEntry,
    nutritional_info_per_100g: updatedNutrition,
    total_nutritional_info_consumed: updatedTotal
  });
};
```
