## 🔄 使用方法

### 用户登录
1. 访问任何需要登录的页面
2. 点击"登录"按钮
3. 选择登录方式：
   - **OAuth登录**：使用Linux.do账号
   - **账号密码**：使用邮箱和密码
4. 完成登录

### 用户注册
1. 在登录页面点击"立即注册"
2. 填写注册信息：
   - 用户名（实时检查可用性）
   - 邮箱（实时检查可用性）
   - 密码（实时强度检查）
   - 可选：显示名称、邀请码
3. 提交注册
4. 检查邮箱进行验证

### 密码重置
1. 在登录页面点击"忘记密码"
2. 输入邮箱地址
3. 检查邮箱中的重置链接
4. 设置新密码
